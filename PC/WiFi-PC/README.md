# PC Wi-Fi Module (Phase 4)

This module is reserved for Phase 4: Local Wi-Fi control via the STouch Desktop Receiver.

## Contents
- `pairing/`: Short-lived temporary QR code token exchange.
- `connection/`: Local authenticated WebSocket client.
- `protocol/`: JSON payload schema for pointer and keyboard events.
- `receiver-integration/`: Desktop receiver handshake and revocation.
