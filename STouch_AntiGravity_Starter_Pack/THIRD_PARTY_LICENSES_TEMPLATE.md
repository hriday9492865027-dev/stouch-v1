## Rules
1. Verify the exact licence in the checked-out repository and all dependencies before copying code.
2. Preserve copyright, licence and NOTICE files as required.
3. Record the exact commit hash or release tag.
4. Do not incorporate GPL-licensed code into a proprietary distribution unless the project owner accepts the applicable obligations.
5. If licence status is unclear, do not copy the code until clarified.
